# Survival Paradise — World Master Layout Drafts

These three visual world-overview drafts are **concept art only**, not canonical geography, production-ready full biome maps, or playable levels. They were generated during the 2026-10-20 world expansion pass. The generator repeatedly created *global overviews* rather than the specifically requested single-biome maps; none is counted as a new Desert, Grassland, Swamp or Coastal map.

| World draft | Purpose | Known limitation |
| --- | --- | --- |
| [Concept 01 — moodboard](SP_World_MasterOverview_Concept_01.webp) | Fast cross-biome relationship ideas | Includes insets, legend, UI text; no direct in-engine value |
| [Concept 02 — continental layout](SP_World_MasterOverview_Concept_02.webp) | Starting landscape and travel-network composition | Stylized broad geography, text annotations, not tileable |
| [Concept 03 — alternate continental layout](SP_World_MasterOverview_Concept_03.webp) | Alternate regions and road connections | Includes unapproved volcanic biome/islands, text and fantasy styling |

The original full-resolution PNGs are retained in the project Library under `/SurvivalParadise/MapSources/`. GitHub stores high-quality WebP viewing versions, with source and repository SHA-256 recorded in [the concept image manifest](WORLD_LAYOUT_CONCEPT_MANIFEST.json).

**Authoritative production sequence:** [World biome production roadmap](../../../docs/asset-production/world/WORLD_EXPANSION_PLAN.json). Remaining biome regions should be created as full-frame individual top-down 2.5D environments, without labels or atlas insets, then decomposed into game-ready terrains and placeable objects, colliders and persistent chunks.
