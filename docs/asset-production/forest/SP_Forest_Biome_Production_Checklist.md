# Survival Paradise — Forest Biome Nature Checklist

**Status:** 84 existing isolated transparent RGBA PNGs accepted as forest **prototype assets**; in-engine scale, zoom and visual quality checks remain pending.

**Source:** `SurvivalParadise_Nature_Collection_v01.zip` (archived forest collection); all asset filenames below are from the original archive, not newly invented.

**Biome policy:** Forest-specific nature collection only. Other biomes require their own nature assets.

**Art standards:** Single isolated object per file, transparent background, consistent oblique top-down lighting, gritty realistic material rendering, no scenery or text.
